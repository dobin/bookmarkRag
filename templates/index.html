REST API

All endpoints accept JSON and return JSON. Replace <notebook> with a notebook name from the table.

Search

POST /api/search or POST /<notebook>/api/search

curl -X POST "http://localhost:5000/api/search" \
  -H 'Content-Type: application/json' \
  -d '{"query":"Windows exception handling","kind":"semantic"}'

Public endpoint powering the search box above. kind is "content", "summary", or "semantic". For /api/search, notebook is optional (omit it to search all). Content and summary searches are literal and case-insensitive. Semantic search skips un-indexed notebooks, listing them in result.unavailable_notebooks.

MCP server

Configure the included read-only stdio server in an MCP-capable client.

Use .vscode/mcp.json, which starts mcp_server.py with the project virtual environment.

  • list_bookmarks(notebook=None) lists catalog bookmarks.
  • search_documents(query, notebook=None, source="both", limit=100) searches stored Markdown and summaries.

MCP searches are literal, case-insensitive, and do not invoke GraphRAG or an LLM.
