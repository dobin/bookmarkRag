REST API

All endpoints accept JSON and return JSON. Replace <notebook> with a notebook name from the table.

File search

POST /<notebook>/api/file-search

Content-Type: application/json

{"query": "Windows exception handling", "source": "both", "limit": 100}

Use source: "summaries" for .llm summaries, "input" for full .md content, or "both" (the default). Search is literal and case-insensitive.

Semantic search

POST /<notebook>/api/semantic-search

Content-Type: application/json

{"query": "Windows exception handling", "limit": 10}

This endpoint requires login when authentication is enabled. It returns matching vector text units and metadata; it does not generate an answer.

MCP server

Configure the included read-only stdio server in an MCP-capable client.

Use .vscode/mcp.json, which starts mcp_server.py with the project virtual environment.

  • list_bookmarks(notebook=None) lists catalog bookmarks.
  • search_documents(query, notebook=None, source="both", limit=100) searches stored Markdown and summaries.

MCP searches are literal, case-insensitive, and do not invoke GraphRAG or an LLM.
